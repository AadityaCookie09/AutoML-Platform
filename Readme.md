\# AutoML Platform — Single File AI/ML Trainer



A professional single-file AutoML web application built using Python and Streamlit.



This project allows users to upload CSV datasets, automatically preprocess data, train machine learning models, evaluate performance, and generate predictions — all through a clean beginner-friendly interface.



\---

Note: Please use light mode!,toggle by selecting the three dots on top right.


\## Features



\- CSV dataset upload

\- Automatic preprocessing

\- Missing value handling

\- Categorical data encoding

\- Automatic classification/regression detection

\- Random Forest model training

\- Feature importance analysis

\- Interactive prediction interface

\- Model export (`.pkl`)

\- Beginner Mode + Advanced Mode

\- Professional SaaS-style UI

\- Fully local/offline execution

\## Installation



Clone the repository:



```bash

git clone https://github.com/your-username/automl-platform.git

cd automl-platform

```



Install dependencies:



```bash

pip install streamlit pandas numpy matplotlib scikit-learn joblib

```



\---



\## Running the App



Start the Streamlit server:



```bash

streamlit run app.py

```



The application will open automatically in your browser.
